## What is the Odia Picture Dictionary?

The Odia Picture Dictionary is a free visual dictionary that works as:

- An **Odia dictionary** (including Odia-to-Odia meanings)
- A **picture dictionary** / **visual dictionary** with image cards
- A trilingual English–Hindi–Odia lookup tool with text-to-speech

It is useful for students, kids learning Odia script, and anyone who wants a fast offline Odia dictionary in the browser.

---

## Key Features

| Feature | Details |
|---|---|
| Picture cards | Visual word cards for faster vocabulary learning |
| Trilingual search | Search in Odia, English or Hindi — script auto-detected |
| Text-to-speech | Hear Odia, English and Hindi pronunciation |
| Odia-to-Odia mode | Full Odia meaning lookup, not only translation |
| Offline reader | Paste text or upload PDF / DOCX / TXT and read aloud |
| Floating mode | Undock the dictionary as a floating widget |
| Custom words | Add your own Odia–English–Hindi entries |
| Fully offline | Dictionary is stored locally after first load |

## How to Use

1. Open [https://abhayattcc.github.io/Odia-Picture-Dictionary/](https://abhayattcc.github.io/Odia-Picture-Dictionary/)
2. Type a word in Odia, English or Hindi
3. See picture references and meanings
4. Tap 🔊 for pronunciation
5. Use the Reader to open documents and read them aloud offline

No installation and no account required.

---

## Who Is It For?

- Students preparing for Odisha exams who need a reliable Odia dictionary
- Kids learning Odia, English and Hindi through pictures and audio
- Hindi or English speakers learning Odia script and vocabulary
- Anyone who wants a free offline visual dictionary in the browser

---

## Tech Stack

- Pure HTML, CSS and Vanilla JavaScript
- IndexedDB for offline dictionary storage
- Web Speech API for multilingual TTS
- SQL.js (WASM) for local dictionary queries
- PDF.js and DOCX parser for the offline reader

---

## Privacy

Searches stay on your device. There is no login, no tracking of personal data, and no forced ads.
